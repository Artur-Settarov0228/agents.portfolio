# Portfolio Agent

This project is a custom Portfolio Agent system designed for Antigravity. The Agent collects user information step-by-step and automatically generates a modern, responsive, and professional portfolio website.

## Agent Structure and Skills
Each section is kept in a separate SKILL.md file.

- **About Skill**: Collects name, bio, photo, etc.
- **Contact Skill**: Asks for contact methods and links.
- **Skills Skill**: Gathers programming languages, frameworks, and tools.
- **Experience Skill**: Collects work experience (without Start/End Dates).
- **Education Skill**: Collects educational background (without Start/End Dates).
- **Projects Skill**: Asks for projects.
- **Frontend Skill**: Generates the portfolio code based on all collected data.

## Workflow Sequence

```text
User
↓
Portfolio Agent
↓
About Skill
↓
Contact Skill
↓
Skills Skill
↓
Experience Skill
↓
Education Skill
↓
Projects Skill
↓
Frontend Skill
↓
Portfolio
```

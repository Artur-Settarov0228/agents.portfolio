# Frontend Skill

This Skill runs last, after all information has been collected.

## Structural Order
The portfolio must be created in the following order:
1. Header / Navbar
2. Hero / About
3. Skills
4. Experience
5. Education
6. Projects
7. Contact
8. Footer

## Core Rules
- The frontend must only use the actual information collected. Do not invent user information.
- There should be no Start Date or End Date anywhere.
- Properly link the collected images and URLs.
- Design must be modern, clean, professional, and responsive.

## Launch and Testing (Test & Fix)
- Check the Desktop and Mobile views.
- Identify and fix console errors and broken links.
- Fix errors and prepare the Final Portfolio.

# About Skill

This Skill must run first and is responsible for collecting the user's personal details.

## Required Information
- Name
- Profile Picture
- Profession / Professional Role
- Short Bio
- Location

## Rules
- The user can provide the information all at once or step-by-step.
- Return the collected data to the Agent in a structured format.
- Do not invent information.

# Experience Skill

This Skill runs after the Skills Skill.

## Required Information
Ask for the following details for each workplace:
- Company Name
- Position / Role
- Location
- Description

## Rules
- IMPORTANT: Start Date and End Date ARE NOT REQUIRED. Do not create or ask for these fields.
- Support multiple workplaces.
- Do not invent information.

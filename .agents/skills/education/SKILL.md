# Education Skill

This Skill runs after the Experience Skill.

## Required Information
Ask for the following details for each educational institution:
- University / Institution
- Field / Major
- Location
- Description

## Rules
- IMPORTANT: Start Date and End Date ARE NOT REQUIRED. Do not create or ask for these fields.
- Support multiple educational institutions.
- Do not invent information.
